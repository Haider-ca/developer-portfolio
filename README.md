## Installation

Clone repository

```bash
git clone https://github.com/Haider-ca/developer-portfolio.git
```

Open:

```bash
cd developer-portfolio
```

Install:

```bash
npm install
```

Run:

```bash
npm run dev
```

Build:

```bash
npm run build
```

Preview:

```bash
npm run preview
```
